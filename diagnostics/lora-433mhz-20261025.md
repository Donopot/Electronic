# Passage de la liaison meteo a 433,92 MHz

Le 25 octobre 2026, l'utilisateur corrige la bande des XL1278-SMT :
433 MHz au lieu de la valeur 169 MHz indiquee precedemment.
Le canal commun devient 433920000 Hz dans firmware/WeatherRadioConfig.h.
Les autres parametres restent SF7, BW31250, CR4/5, preambule8, sync0x12,
CRC, entete explicite, IQ normal, puissance TX2 dBm et intervalle120s.

Les deux firmwares compilent et sont televerses, ecritures verifiees :

- Recepteur COM4, MAC e8:3d:c1:78:b4:b4, profil weather_receiver_433,
  1551790 octets flash / 62924 octets RAM. Le diagnostic HTTP confirme
  FRF=0x6C7AE1, soit 433919982 Hz nominaux apres quantification du
  synthetiseur, pour une consigne 433920000 Hz. Mode=0x8E, configuration OK.
- Sonde COM3, MAC e8:3d:c1:81:ca:70, profil
  enviroterminal_local_web_meteo_tx, 1566664 octets flash / 63220 octets RAM.
  Wi-Fi, BLE et LoRa conserves ; Wi-Fi reconnecte a 192.168.1.65.
  Au demarrage : version0x12/0x12, modes00/00,08/08,88/88, init433920000Hz.

Deux paquets sont recus apres le televersement puis le redemarrage manuel
de la sonde pour observer son demarrage complet. Ils portent tous deux
seq=0, car ils proviennent de deux demarrages successifs ; cela ne valide
pas encore la cadence periodique. Le second paquet correspond exactement
au JSON emis a uptime523ms : 22,9 degres C, 1008,24 hPa, 92 octets.
COM4 confirme la validation meteo et la publication sur le tableau de bord.
L'API confirme sample_count=2, sensor_ok=true, source=lora, Wi-Fi connecte,
RSSI=-126 dBm et SNR=-2 dB. Le signal reste faible malgre la reception ;
aucune conclusion de portee ou de fiabilite de longue duree n'est tiree.

Preuves : diagnostics/transmitter-startup-recovery.log (section
2026-10-25T20:49:21 UTC), diagnostics/lora-link-com4.log,
diagnostics/receiver-radio-433mhz-initial.json.

L'envoi periodique suivant est confirme : seq=1, uptime120558ms,
22,9 degres C / 1008,25 hPa. TxDone sur COM3 et reception du meme JSON
de 95 octets sur COM4, paquet3 a uptime184802ms, RSSI=-126 dBm,
SNR=-1 dB. La mesure est validee et publiee sur le tableau de bord.
Cela confirme aussi le cycle d'envoi de deux minutes apres le demarrage.
Les seize assertions de validation des registres passent avec -Werror,
dont le rejet explicite de l'ancien canal 169 MHz sur les deux cartes.
Etat HTTP des deux cartes conserve dans lora-433mhz-live-status.json.
Les captures se terminent sans perte SPI ni interruption USB.
